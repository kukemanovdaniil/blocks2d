* **[Download](https://github.com/kukemanovdaniil/blocks2d/releases/latest)**

## Controls
* **W | A | S | D** - Player movement
* **R** - Change build mode
* **Left click** - Place block
* **Right click** - Break block
* **Mouse wheel** - Change zoom
* **F8** - Close game
* **F11** - Toggle fullscreen
